# Collaboration

## Public participation rule

List a person or organization publicly only when that participation is explicitly authorized for publication.

Participation in a message thread, meeting, technical discussion, repository view, interface proposal, or informal exchange does not by itself establish partnership, employment, agency, endorsement, ownership, or authority.

## Technical authorship rule

Where a layer contract originates from another system's maintainer, preserve that attribution and do not silently rewrite their technical responsibility as SignalLink's.

~~~text
TREE contract    -> maintainer-defined reasoning boundary
OMNIX contract   -> maintainer-defined governed admissibility boundary
Fidacy contract  -> maintainer confirmation still required for detailed implementation boundary
SignalLink       -> SignalLink-defined provenance/integrity boundary
~~~

## Preferred contribution modes

- layer-contract correction,
- reproducibility result,
- test vector,
- schema correction,
- architecture critique,
- closed/halt condition,
- adversarial/mutation test,
- security observation through the designated security channel,
- pull request tied to a specific issue.
