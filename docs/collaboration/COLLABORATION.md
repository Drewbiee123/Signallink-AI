# Collaboration

## Public participation rule

List a person or organization publicly only when that participation is explicitly authorized for publication.

Participation in a message thread, meeting, technical discussion, repository view, or informal exchange does not by itself establish partnership, employment, agency, endorsement, ownership, or authority.

## Preferred contribution modes

- reproducibility result,
- test vector,
- interface proposal,
- schema correction,
- architecture critique,
- security observation through the designated security channel,
- pull request tied to a specific issue.

## Public contributor entry template

```text
Name / organization:
Public role:
Scope:
Authorized public reference:
Date confirmed:
```

If consent is withdrawn or status changes, update this document rather than preserving stale organizational assumptions.
