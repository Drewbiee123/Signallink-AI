# Collaboration Working Set

This directory is a public, bounded working set for documenting technical collaboration around SignalLink without implying completed integration, partnership, authority, endorsement, or production readiness.

## Start here

- [STATUS.md](./STATUS.md) — current technical state
- [ARCHITECTURE.md](./ARCHITECTURE.md) — system boundaries and interfaces
- [REFERENCE-WORKFLOW.md](./REFERENCE-WORKFLOW.md) — one bounded synthetic interoperability test
- [EVIDENCE.md](./EVIDENCE.md) — claim/evidence register
- [PROVENANCE.md](./PROVENANCE.md) — artifact identity and verification model
- [COLLABORATION.md](./COLLABORATION.md) — participation rules
- [NEXT-STEPS.md](./NEXT-STEPS.md) — executable next actions

## Claim-state vocabulary

- **VERIFIED** — independently reproducible or supported by published evidence.
- **DEMONSTRATED** — shown in a bounded test.
- **SYNTHETIC** — uses simulated or non-production data.
- **EXPERIMENTAL** — implemented but not production-ready.
- **PROPOSED** — architecture or integration not yet completed.
- **NOT CLAIMED** — explicitly outside the present evidence boundary.

The governing rule is simple: public claims must not exceed public evidence.
